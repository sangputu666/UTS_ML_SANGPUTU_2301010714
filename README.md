Deskripsi Masalah & TujuanPerencanaan pariwisata berkelanjutan membutuhkan estimasi belanja wisatawan yang akurat untuk mendukung kebijakan ekonomi daerah dan manajemen kapasitas destinasi.Jenis Tugas: Regresi (Supervised Learning)Variabel Target (y): total_tourist_spending_idr (Total pengeluaran wisatawan dalam Rupiah)Fitur Prediktor (X):Numerik: trip_duration_days, hotel_room_rate_per_night_idr, travel_party_size, distance_from_origin_km, local_experience_count, dll.Kategorik & Biner: tourist_origin_category, destination_province, accommodation_type, travel_purpose, is_super_priority_destination, dll.Metrik Evaluasi:MAE (Mean Absolute Error) — mengukur rata-rata selisih absolut prediksi dalam Rupiah.RMSE (Root Mean Squared Error) — memberi penalti lebih besar pada kesalahan prediksi ekstrem.$R^2$ Score (Coefficient of Determination) — mengukur proporsi variansi pengeluaran yang berhasil dijelaskan oleh model.2. Alur Pengerjaan (Pipeline)Pemahaman Data & EDA (Exploratory Data Analysis):Pemeriksaan dimensi data, tipe data, missing values, dan duplikasi.Analisis korelasi Pearson dan visualisasi distribusi target maupun fitur kategorik.Pra-pemrosesan Data (Data Preprocessing):Penghapusan kolom ID, metadata, serta fitur turunan target (data leakage prevention).Pembagian data latih dan data uji (Train-Test Split 80:20 dengan random_state=714).Transformasi fitur menggunakan ColumnTransformer dan Pipeline (StandardScaler untuk fitur numerik dan OneHotEncoder untuk fitur kategorik).Pemodelan (Modeling) & Validasi:Pelatihan beberapa model regresi: Linear Regression (baseline), Ridge Regression, dan Random Forest Regressor.Evaluasi stabilitas model menggunakan 5-Fold Cross-Validation.Evaluasi & Interpretasi:Perbandingan performa model pada test set menggunakan MAE, RMSE, dan $R^2$.Analisis residual dan identifikasi fitur paling berpengaruh terhadap pengeluaran wisatawan.4.
